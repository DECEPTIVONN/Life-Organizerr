Design System & Hud Specs

Componente: Navbar HUD v4.5

■ CONCEITO DA NAVBAR HUD MOBILE

Esta especificação descreve a arquitetura e implementação da Curved Futuristic HUD Bar, uma barra de navegação inferior mobile estilizada com design cibernético de alta fidelidade e HUD curvo em SVG.

■ DIFERENCIAÇÃO MOBILE VS DESKTOP

Para garantir uma transição limpa e evitar o carregamento ou renderização indevida de elementos em telas de tamanhos diferentes, utilizamos as classes de utilidade responsiva do Tailwind:

🖥️ Layout Desktop

Exibido apenas em telas maiores.

hidden md:flex
📱 Layout Mobile

Exibido apenas em telas menores de 768px.

md:hidden fixed

Evitando Cliques Fantasmas (Pointer Events)

Como a barra HUD mobile possui uma curvatura de altura elevada (92px), a div pai precisa flutuar sobre o conteúdo do site. Para evitar bloquear cliques no conteúdo atrás das áreas vazias da barra, aplicamos:

  • pointer-events-none na div pai de posicionamento absoluto da barra inferior.
  • pointer-events-auto estritamente no elemento SVG de fundo e no container dos botões, reativando a interatividade exatamente onde o HUD é desenhado.

■ PASSO A PASSO DE RECRIAÇÃO

Passo 1

O Fundo Curvo em SVG Matemático

O segredo do visual futurista está no SVG responsivo com esticamento desproporcional (preserveAspectRatio="none") e caixa de visualização de 0 a 100 coordenadas.

d="M 0 30 Q 50 0 100 30 L 100 100 L 0 100 Z"
  • M 0 30: Move a caneta para o lado esquerdo a 30% da altura do elemento.
  • Q 50 0 100 30: Desenha uma curva quadrática de bezier que sobe até o topo (y=0) no meio (x=50) e desce até (x=100, y=30) na direita.
  • L 100 100 L 0 100 Z: Fecha o desenho fechando os cantos inferiores da tela criando o preenchimento.
Passo 2

Glows Dinâmicos e Estados de Destaque

Os botões utilizam filtros de drop-shadow CSS e transição suave no translate Y para criar o efeito de elevação tridimensional quando ativos.

<!-- Estado Ativo -->
class="text-[#fbbf24] scale-115 -translate-y-2.5 filter drop-shadow-[0_0_10px_rgba(251,191,36,0.8)] transition-all duration-300"
Passo 3

Ação de Gaveta Deslizante (Drawer de Categorias)

O botão central "Categorias" dispara o estado para abrir uma gaveta lateral que desliza da direita ou esquerda usando Framer Motion em React, ou simples classes de transição no HTML nativo (translate-x-0 / translate-x-full).

■ CÓDIGO FONTE REACT + TAILWIND

JSX / TSX

Aqui está o trecho limpo e modularizado em React (com Framer Motion e Lucide React) pronto para ser adicionado ao seu projeto: 

{/* PAI FIXADO NO FUNDO */}
<div className="md:hidden fixed bottom-0 left-0 right-0 h-[92px] z-[45] pointer-events-none">
  
  {/* SVG CURVO COM EFEITO NEON */}
  <div className="absolute inset-0 pointer-events-auto">
    <svg className="w-full h-full filter drop-shadow-[0_-8px_16px_rgba(139,92,246,0.35)]" viewBox="0 0 100 100" preserveAspectRatio="none">
      {/* Linha brilhante superior */}
      <path 
        d="M 0 30 Q 50 0 100 30 L 100 100 L 0 100 Z" 
        fill="none" 
        stroke="#8b5cf6" 
        strokeWidth="2" 
      />
      {/* Fundo escuro HUD */}
      <path 
        d="M 0 30 Q 50 0 100 30 L 100 100 L 0 100 Z" 
        fill="#030510" 
        opacity="0.98"
      />
    </svg>
  </div>

  {/* BOTÕES DE NAVEGAÇÃO */}
  <div className="absolute inset-x-0 bottom-0 top-3 flex items-start justify-around px-2 pb-safe pointer-events-auto">
    {bottomItems.map((item) => (
      <button
        key={item.id}
        onClick={item.action}
        className="relative flex flex-col items-center justify-center w-16 h-16 group cursor-pointer"
      >
        {/* Ícone com Glow Dinâmico */}
        <div 
          className={`transition-all duration-300 ${
            item.isActive 
              ? "text-[#fbbf24] scale-115 -translate-y-2.5 filter drop-shadow-[0_0_10px_rgba(251,191,36,0.8)]" 
              : "text-gray-400 group-hover:text-white"
          }`}
        >
          {item.icon}
        </div>

        {/* Indicador Ativo */}
        {item.isActive && (
          <>
            {/* Linha/Pill sob o ícone */}
            <div className="absolute bottom-6.5 w-8 h-1 bg-[#fbbf24] rounded-full shadow-[0_0_12px_#fbbf24] z-10" />
            {/* Texto reduzido */}
            <span className="absolute bottom-1 text-[8px] font-orbitron font-extrabold tracking-widest text-[#fbbf24] uppercase">
              {item.label}
            </span>
          </>
        )}
      </button>
    ))}
  </div>
</div>
